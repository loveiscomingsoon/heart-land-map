# HEART LAND แผนที่และผังพื้นที่

เว็บแผนที่ใช้ MapLibre GL JS รุ่นเดียวกับโครงการศรีจันทร์ เปิดด้วยมือถือ แท็บเล็ต และคอมพิวเตอร์ที่รองรับ WebGL

## ใช้งาน

- แปลงที่ดิน: ค้นหมายเลขโฉนดแล้วกดดูตำแหน่ง
- วางผัง: ปักจุด วาดเส้นทาง หรือวาดโซน ตั้งชื่อ ประเภท และสี กดรายการเพื่อแก้ไขหรือลบ ปรับตำแหน่งได้โดยลากจุด
- ภาพผังทับ: เลือก PNG JPEG หรือ WebP ขนาดไม่เกิน 8 MB ลากมุมทั้งสี่เทียบตำแหน่งจริง และปรับความทึบ
- สำรองผังพร้อมภาพ: ดาวน์โหลด JSON ที่เก็บทั้งรูปและตำแหน่งมุม นำไปเปิดในเครื่องอื่นได้
- ส่งออกและนำเข้า GeoJSON สำหรับผังเวกเตอร์
- สลับภาพถ่ายพื้นที่ แผนที่ถนน หรือแปลนพื้นเรียบ และมุมมอง 2D / 3D ได้ มุม 3D เป็นการเอียงแผนที่ ไม่ใช่โมเดลรังวัดอาคาร

## แหล่งพิกัด

ค้นจาก LandsMaps กรมที่ดิน https://landsmaps.dol.go.th/ วันที่ 8 พฤศจิกายน 2569 จังหวัดเชียงใหม่ อำเภอสันกำแพง ตำบลสันกลาง ตามหมายเลขที่ผู้ใช้ให้ 13 แปลง ได้แก่ 56738 56737 56736 56741 56745 55749 55750 55748 55747 339 341 69251 และ 101667

หมุดเป็นค่าพิกัดแปลงที่ LandsMaps แสดง ไม่ใช่พิกัดมุมเขต และไม่สร้างเส้นขอบเขตจากการเชื่อมหมุดเหล่านี้ หมายเลข 55749 กับ 101667 เป็นคนละตำแหน่ง จึงเก็บแยกกัน ภาพแผนผังเดิมสามภาพเปิดดูประกอบได้ และเก็บต้นฉบับอยู่ในแฟ้มคุยครั้งที่สอง

## การจัดเก็บ

ผังที่แก้และภาพที่เลือกเก็บในเบราว์เซอร์เครื่องนั้น ไม่ซิงก์กับคนอื่นโดยอัตโนมัติ ต้องกดสำรองผังพร้อมภาพเพื่อส่งต่อหรือเก็บระยะยาว ภาพที่เลือกไม่ได้อัปโหลดไปเซิร์ฟเวอร์ของแผนที่ การล้างข้อมูลเบราว์เซอร์อาจทำให้ร่างหาย แต่เปิดไฟล์สำรองกลับมาได้

พิกัดอ้างอิงเผยแพร่เป็น GeoJSON และ CSV ใน data ส่วนเสียงประชุม รายชื่อผู้ร่วมวง และภาพถ่ายบุคคลไม่ได้รวมในเว็บนี้

## แนวเขตที่ดินสีแดง
เพิ่มปุ่ม “แนวเขตที่ดินสีแดง” เปิด–ปิดชั้นเส้นแดงแยกจากหมุดและผังใหม่ ขณะนี้ยังไม่มีข้อมูลพิกัดมุมเขตจริง จึงไม่มีเส้นแสดงจนกว่าจะนำเข้าข้อมูล

กด “จัดการรูปแปลงที่ดิน” เพื่อนำเข้า GeoJSON FeatureCollection รูปแบบ Polygon พิกัด WGS84 [ลองจิจูด, ละติจูด] แต่ละรูปมี properties.deed เป็นหมายเลขโฉนดในรายการ 13 แปลง และ properties.source เป็นที่มาข้อมูล (ถ้ามี) รองรับวงขอบและรูภายใน ตรวจวงปิด พิกัดบริเวณพื้นที่ และหมายเลขซ้ำ แสดงตามพิกัดไฟล์ที่นำเข้า การตรวจรูปแบบไม่ใช่การรับรองความถูกต้องของงานรังวัด

แนวเขตที่นำเข้าจะถูกเก็บในเบราว์เซอร์และรวมในแฟ้ม “สำรองผังพร้อมภาพ” ใช้ย้อนการแก้ล่าสุดเพื่อคืนชุดข้อมูลก่อนนำเข้าได้

แหล่งข้อมูลกรมที่ดิน: https://data.go.th/dataset/mapland-parcel ระบุว่าการใช้ API ต้องขออนุญาตและรับ Consumer-Key/Secret จึงยังไม่เชื่อมต่อ API อัตโนมัติ ไม่มีการสร้างแนวเขตจริงด้วยการเชื่อมหมุดกลางแปลง
